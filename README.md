# UserScript

油猴脚本集合，用于日常网页体验增强。

## 脚本列表

| 脚本 | 文件 | 功能 |
| --- | --- | --- |
| 搜索栏增强 | [SearchTab.js](./SearchTab.js) | 在搜索页面顶部切换搜索引擎，沿用当前搜索词 |

## 安装

1. 在浏览器中安装 Tampermonkey（油猴）扩展。
2. 打开 [SearchTab.js](./SearchTab.js)，复制完整源码。
3. 在 Tampermonkey 中新建脚本，替换编辑器中的默认内容并保存。
4. 打开支持的搜索页面，或刷新已打开的页面。

更新时，在 Tampermonkey 编辑器中用新版完整源码替换并保存即可。

## 搜索栏增强

### 功能

- 默认收录 Google、百度、Bing、DuckDuckGo、GitHub、知乎和 B站。
- 搜索栏位于页面顶部，搜索引擎图标居中，右侧齿轮可打开设置。
- 悬停显示站点名称，对应图标放大；点击时读取当前搜索词并跳转。
- 尽量避免遮挡页面顶部的搜索框。
- 图标无法加载时显示站点名称的首字或前两个字符。
- 支持自定义搜索网站、排列顺序和新窗口打开。

### 使用

1. 打开支持的搜索页面，输入搜索词。
2. 点击顶部的搜索引擎图标，即可使用当前搜索词切换搜索引擎。
3. 点击右侧齿轮，可添加、删除或调整搜索网站。

### 自定义网站

在设置中编辑列表，每行一个网站：

```text
[名称] [搜索网址] [新窗口] (关键词选择符)
```

名称和搜索网址必填，网址以 `http://` 或 `https://` 开头，并以 `#keyword#` 表示搜索词。`[新窗口]` 和 `(关键词选择符)` 可以省略。

```text
[百度搜索] [https://www.baidu.com/s?wd=#keyword#]
[知乎搜索] [https://www.zhihu.com/search?type=content&q=#keyword#] [新窗口]
```

- 列表顺序就是按钮顺序。
- 添加 `[新窗口]` 后，在新标签页打开该目标，通常不在该目标页面显示搜索栏。
- 通常无需填写关键词选择符；如无法读取搜索词，可按下方说明指定搜索框。
- 修改后点击“保存”生效。“恢复默认”会先将编辑区替换为默认名单，点击“保存”后才生效。
- 格式错误、无效网址、缺少搜索词占位符或选择符语法错误的配置行会被跳过；保存时只保留有效行。没有有效项时保留原配置，并提示检查。
- 已保存的自定义列表会保留；如需切换到七个默认站点，请恢复默认并保存。

#### 关键词选择符

关键词选择符用于指定：在该网站的页面中，从哪个搜索框读取搜索词。通常留空即可；如果自定义网站无法自动识别搜索词，或读取了错误的输入框，可以填写这一项。

将选择符用英文圆括号包住，放在对应网站配置行的末尾。常见写法如下：

| 搜索框的属性 | 填写示例 |
| --- | --- |
| `id="search_input"` | `(#search_input)` |
| `name="query"`，且为输入框 | `(input[name=query])` |
| `class="search-input"`，且为输入框 | `(input.search-input)` |

例如，某个网站的搜索框为 `<input name="query">`，可以这样配置：

```text
[示例站点] [https://example.com/search?q=#keyword#] (input[name=query])
```

在该网站的搜索页面输入“天气”，再点击顶部的其他搜索引擎图标，就会使用这个搜索框里的“天气”进行搜索。

如需查找搜索框属性，可在搜索框上右键选择“检查”，查看对应元素的 `id`、`name` 或 `class`。选择符应尽量只匹配一个搜索框；示例中的网址和属性需要替换为实际网站的内容，修改后点击“保存”。
