# UserScript

油猴脚本集合，用于日常网页体验增强。

## 脚本列表

| 脚本 | 功能 | 源码 | 使用说明 |
| --- | --- | --- | --- |
| 搜索栏增强 | 在页面顶部使用图标切换搜索引擎，沿用当前搜索词，支持自定义网站 | [SearchTab.js](./SearchTab.js) | [查看 Wiki](https://github.com/teiny/UserScript/wiki/%E6%90%9C%E7%B4%A2%E6%A0%8F%E5%A2%9E%E5%BC%BA) |

## 安装与使用

安装、更新及自定义配置说明请参阅 [项目 Wiki](https://github.com/teiny/UserScript/wiki)。
